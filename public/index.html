ข้อมูลสาธารณะ · อำเภอเมืองระยอง

ติดตามน้ำต้นทาง
พร้อมระดับน้ำในพื้นที่

ข้อมูลจากอ่างเก็บน้ำ 3 แห่ง ระดับน้ำจากสถานีใกล้เมือง และฝนในอำเภอเมืองระยอง เพื่อช่วยให้ชุมชนเห็นสถานการณ์ในภาพเดียว

กำลังติดต่อแหล่งข้อมูลเวลาไทย (ICT)
ระดับน้ำที่สถานีวัด ไม่ใช่ระดับน้ำท่วมบนถนนในตัวเมือง หากพื้นที่ของคุณมีน้ำท่วม โปรดใช้สภาพจริงและประกาศจากหน่วยงานท้องถิ่นประกอบ

01 / ระดับน้ำ

สถานีตรวจวัดใกล้พื้นที่

ดูต้นทาง ↗

หนองบัวอยู่บนลำน้ำคลองใหญ่ในอำเภอบ้านค่าย (ต้นน้ำของตัวเมือง) ส่วนบ้านเขาโบสถ์อยู่ในตำบลทับมา อำเภอเมืองระยอง บนคลองกระเฉด สถานีทั้งสองไม่ได้วัดระดับน้ำถนนในย่านใจกลางเมือง

02 / ต้นน้ำ

อ่างเก็บน้ำที่เชื่อมสู่แม่น้ำระยอง

ข้อมูลรายวันจากกรมชลประทาน

“น้ำระบาย” เป็นค่าที่ API รายงานตามวันที่แสดง ไม่ใช่ปริมาณน้ำที่จะถึงตัวเมืองทันที และเอกสาร API ไม่ระบุหน่วยเวลาของช่องนี้

กราฟแสดงค่าควบคู่กันเพื่อช่วยติดตามเวลา ยังไม่สามารถใช้สรุปว่าการระบายจากอ่างเป็นสาเหตุของน้ำท่วมจุดใด เพราะฝนในพื้นที่ ทางระบายน้ำ และสภาพปลายน้ำก็มีผล

04 / ฝนในพื้นที่

ฝนสะสม 24 ชั่วโมง

ThaiWater ↗

แสดงสถานีที่มีข้อมูลในอำเภอเมืองระยอง เรียงจากปริมาณฝนมากที่สุด ลูกศรสีเขียว เหลือง และแดง เปรียบเทียบกับข้อมูลก่อนหน้าที่มีค่าของสถานีเดียวกัน ไม่ใช่การวัดปริมาณฝนทุกถนน

05 / พยากรณ์

คาดการณ์ฝน 24 ชั่วโมงข้างหน้า

Open-Meteo ↗

พยากรณ์จาก Open-Meteo สำหรับจุดกึ่งกลางตัวเมืองระยอง ใช้เพื่อวางแผนเบื้องต้นเท่านั้น ฝนจริงอาจต่างกันในแต่ละย่าน
